# LLD-design-skill

Developed an LLD (Low-Level Design) skill by synthesizing modern software design principles from:<br>

《Simple Made Easy》✅<br>
《A Philosophy of Software Design, 2nd Edition》✅(APOSD2)<br>
《Parse, Don't Validate》✅<br>
《Domain Modeling Made Functional》✅(DMMF)<br>
《Functional Core, Imperative Shell》✅(FCIS)<br>

The skill distills these principles into a practical, reusable framework for designing software that minimizes accidental complexity, makes invalid states unrepresentable, keeps domain logic pure, and isolates side effects and dependencies.<br>
