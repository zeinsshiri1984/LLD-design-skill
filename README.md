# LLD-design-skill

Developed an LLD (Low-Level Design) skill by synthesizing modern software design principles from:

《Simple Made Easy》✅

《A Philosophy of Software Design, 2nd Edition》✅(APOSD2)

《Parse, Don't Validate》✅

《Domain Modeling Made Functional》✅(DMMF)

《Functional Core, Imperative Shell》✅(FCIS)

The skill distills these principles into a practical, reusable framework for designing software that minimizes accidental complexity, makes invalid states unrepresentable, keeps domain logic pure, and isolates side effects and dependencies.
